# Fixly

Fixly is a minimal complaint tracker for small support teams: log complaints, assign an owner, track status and priority, and keep internal notes. Prototype: runs in the browser and stores data in localStorage.

## Run it
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Project docs
- `AGENTS.md`: standing instructions for OpenCode
- `docs/PRD.md`: what to build and how it behaves
- `docs/DESIGN.md`: visual rules and tokens
- `docs/PROMPTS.md`: build slices, one prompt each
- `docs/TEST-CHECKLIST.md`: manual tests and usability script
- `docs/PERSONAS.md`: discovery inputs
- `docs/seed-data.json`: sample data
